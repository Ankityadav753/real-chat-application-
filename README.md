
# Real-Time Chat Application

This is a full-stack real-time chat application developed using the MERN stack and Socket.io.  
The application supports one-to-one messaging, group chats, live typing indicators, authentication, and online user status updates.

---

## Features

- User Authentication with JWT
- One-to-One Messaging
- Group Chat Functionality
- Real-Time Messaging using Socket.io
- Typing Indicators
- Online/Offline Status
- Protected Routes
- REST API Integration
- Responsive User Interface

---

## Technologies Used

### Frontend
- React.js
- Redux Toolkit
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Real-Time Communication
- Socket.io

### Authentication
- JWT Authentication
